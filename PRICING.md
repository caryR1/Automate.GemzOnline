# Gemz pricing model & rate sheet

**Source:** Cary, finalized 2026-09-26 (handoff email draft "Awesome").
**This is a living, permanently growing document.** Every newly priced item gets
a permanent row in the rate sheet below — see the standing rule in `CLAUDE.md`.
Never re-research an item that already has a row; quote from it.

## Pricing model

1. **Recurring-service setup fee** (GoHighLevel-type services): flat one-time
   **$100** — flipping switches, activating automations for Leads & Reviews /
   AI Attendant / Complete.
2. **Consultation / scope-planning fee** (custom projects; distinct from the
   setup fee): back-and-forth meetings to define requirements before building.
   Hourly, **$25/hr** now. Planned increase to $30–$35/hr once Cary has run
   more real client consultations — *not yet in effect*.
3. **Website build — static tier:** **$100 per significant top-level section**
   (new build). A "significant section" = a distinct top-level topic that would
   warrant its own page in a multi-page site — applies even on a single
   scrolling page. Subsections don't count separately. Static/display content
   only.
4. **Website refresh tier:** **$60 per significant section** (same counting
   rule), for editing/updating an existing site.
5. **Website build — custom-coded tier:** anything needing a database or
   third-party integration (booking, logins, payments, CRM, search,
   calculators, ecommerce). No fixed figure — priced per project via the
   standing rule (interview + research + add a row).
6. **Content generation add-on:** **$20 per AI-generated blog article**
   (two-image format).
7. **Custom graphics add-on** (by complexity): simple (icon/basic edit)
   **$15–$25**; mid (styled illustration/custom hero image) **$50–$75**;
   fully custom (detailed illustration/branded set) **$100–$150**.
8. **Proposal process:** the client-facing site map / mock-up doubles as the
   pricing tool — each significant section on it is a direct priced line item.
9. **Pilot case — Au-Some Notarific (Melicia's site, au-somenotarific.com,
   repo caryR1/Au-some):** 7 sections × $100 = $700 standard, discounted to
   **$400 flat** (friends-and-family). Her actual final price.

## Business policies

Decided with Cary 2026-09-26 (first batch — see Open items for what's still undecided):

1. **Payment terms:** deposit + milestone payments. For multi-section builds,
   split into thirds — e.g. 1/3 up front before work starts, 1/3 at the
   midpoint/draft review, 1/3 on completion before final files/credentials are
   handed over. For a small single-section job, collapse to deposit + final.
   Exact milestone split can flex per project size; the principle (never 100%
   up front, never 100% on delivery) is fixed.
2. **Revisions:** **2 rounds included per section**, then **$25/hr** (the
   consultation rate) for anything beyond that.
3. **Friends-and-family discount:** standard **40% off**. (Melicia's actual
   discount was ~43%, treated as a one-off close to the new standard rate
   rather than the rate itself.)
4. **First consultation:** **$25**, credited toward the project if the client
   goes ahead. Not free, not a sunk cost for a committed client.

## Rate sheet — market comparison (client-facing positioning tool)

Add every newly priced item as a new row. Columns: low end is budget/overseas
freelancer, then typical US freelancer, then agency.

| Item | Cary's rate | Typical freelancer range | Agency / high-end range |
|---|---|---|---|
| New site, per significant section | $100 | $300–$1,000+ per page | $1,000+ per page (agency full sites $3,000–$15,000 total) |
| Site refresh, per significant section | $60 | (use static range above until refined) | (use static range above until refined) |
| Consultation / scope planning, per hour | $25/hr now (planned $30–$35/hr) | $30–$60/hr junior; $75–$150/hr experienced | $100–$150/hr US boutique; $175–$300/hr enterprise |
| AI-generated blog article (2-image format) | $20 | $50–$150/article (human writer) | $75–$200+/article (agency copywriter) |
| Custom graphic — simple (icon/basic edit) | $15–$25 | ~$50–$300 | $500+ |
| Custom graphic — mid (illustration/hero image) | $50–$75 | $200–$500 | $500–$1,500+ |
| Custom graphic — fully custom (detailed/branded set) | $100–$150 | $500–$1,500+ | $2,000+ |
| Recurring service setup fee (GHL-type) | $100 | $50–$200 | varies, often bundled into agency retainer |
| Custom-coded feature/integration (general) | TBD per project | $500–$2,000/integration | thousands+; full ecommerce $3,000–$10,000+ |

**Overall positioning:** deliberately below typical freelancer full-site pricing
($1,500–$8,000) and agency pricing ($5,000–$15,000+), while staying above
rock-bottom global-freelancer rates — the accessible-but-not-cheapest middle.
